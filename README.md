# PC12 segmentation score cube

Interactive comparison of segmentation approaches for PC12 neurite morphology analysis.

**Live page:** https://erengineer35.github.io/pc12-segmentation-score-cube/

Part of a final-year engineering project on NGF-induced neuronal differentiation in
PC12 cells: segmenting soma and neurites from fluorescence microscopy and measuring
morphology (neurite length, branch points, Sholl profile, Das criterion).
