    About this benchmark

    All three teams run the same task with different methods. Everything below is fixed so that every run in the cube can be compared with every other run.

    Soma F1 @ IoU 0.5

    Predicted soma instances are matched one-to-one to ground-truth instances; a pair counts as a match only if its intersection-over-union is at least 0.5. Matched pairs are true positives (TP), unmatched predictions false positives (FP), unmatched ground-truth somata false negatives (FN).

    F1 = 2·TP / (2·TP + FP + FN)

    Tells whether each cell body is detected and kept separate from its neighbours. Merged or split cells both lower it.

    Neurite clDice

    Both neurite masks are reduced to one-pixel skeletons (S) and compared with the other mask's volume (V), following Shit et al., CVPR 2021.

    Tprec = |Spred ∩ Vgt| / |Spred|  ·  Tsens = |Sgt ∩ Vpred| / |Sgt|  ·  clDice = 2·Tprec·Tsens / (Tprec + Tsens)

    Rewards connected centrelines and is insensitive to how thick a neurite is drawn, which plain Dice is not.

    Neurite length error

    L is the total skeleton length of all neurites in an image, in µm.

    error = |Lpred − Lgt| / Lgt × 100 %

    The metric closest to what the lab will report. A segmentation can look good and still get the length wrong.

    Evaluation protocol

    • One locked test split for everyone. Hyperparameters are chosen on the validation split, never on test.
    • One shared evaluation script. Teams submit masks; the script computes the metrics.
    • Metrics are computed per test image and averaged; that average is one run.
    • Scoring at native resolution; predictions are resized back before scoring.
    • Same ground-truth version (write it in the run's note), same training budget for trained models, same post-processing unless post-processing is what is being tested.
    • Record the seed; final candidates get at least three seeds.

    Preprocessing

    Raw
    Intensities as acquired, only scaled to the model's input range.
    Percentile norm.
    Clip to low and high intensity percentiles, rescale to 0–1.
    CLAHE
    Contrast-limited adaptive histogram equalisation; brings out faint neurites.
    Background subtraction
    Removes uneven illumination (rolling ball or top-hat).
    Denoise
    Noise reduction before segmentation.

    Parameters for each step are fixed in the shared config and identical for every model.

    Loss functions

    None (zero-shot)
    The model is used as released, no training.
    BCE + Dice
    Standard pixel-wise plus overlap loss; the baseline.
    Focal + Dice
    Focuses on hard pixels; helps when neurites are a tiny fraction of the image.
    Dice + clDice
    Adds the topology term above to the training objective.
    Tversky
    Weights missed pixels more than extra ones, favouring recall on thin structures.
    Model default
    The loss the original authors train the model with.

    Use Add result for single runs or Import CSV for many. CSV columns: team, model, preprocess, loss, seed, train_n, soma_f1, cldice, len_err, notes.
